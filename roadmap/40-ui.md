# P4 UI 界面（滞后：等 WhaleUI 成型 + wasm 独立）

> 前置：P3 主流程跑通（M3）。UI 排最后的原因只有一个：WhaleUI API 未成型，
> 现在只定“画什么、推什么”（见 `doc-internal/ui-events.md`），不定控件 API。
> 独立性要求：`src/ui/` 单独文件夹 + `fs_ui` 单独 target，只经 FsApi + 事件表与
> `fs_core` 交互；以后 wasm 版 = `fs_core`（Emscripten）+ 浏览器前端。

## fs_ui 架子（WhaleUI 就绪前可先做，不阻塞 P0–P3）

- [ ] `src/ui/` 目录 + `fs_ui` target 接入 xmake（先空壳，保证编译通过）。
- [ ] 事件类型与载荷结构体先行（ui-events.md §2 十四种，一个头文件，不依赖 WhaleUI）。
- [ ] FsApi 客户端封装（同进程直调版；HTTP 版留接口，wasm 拆分时再实现）。
- [ ] md4c 魔改：输出 diff AST，直供流式渲染 diff 更新（高性能关键路径，实现时评估魔改量）。

## 页面（WhaleUI 就绪后按此顺序做）

- [ ] 主页：项目（历史项目 + 新建文件夹/打开文件夹/远程入口）/ 用量统计（图表照 design.json）/
  设置入口 / 新建；探索入口灰色禁用。
- [ ] 会话页顶部栏：tab / 模型 / 思考强度 / 权限 / 自动挡 / 挂起（含待唤醒信息区）。
- [ ] 会话历史：虚拟化一次 10 条；历史渲染一次、当前实时渲染；
  复制/分叉/回滚/遗忘/看 diff（diff div 限高滚动超长截断→跳侧栏）；
  已完成折叠只留 summary；`truncate.hint` 提示条。
- [ ] 左悬浮规划栏：plan 树 + git 摘要（branch/提交态/更新时间→跳侧栏）。
- [ ] 右标签侧栏：用量&上下文 / 本地文件 / 文件操作 / git历史分支 / 子代理历史 /
  toolcall详情 / 历史输入详情；可折叠。
- [ ] 输入框：/ 指令与文件补全上浮；markdown 高亮不渲染；默认 Enter 发送；
  截图/图片附件入口；待唤醒信息显示。
- [ ] 终端区：默认隐藏；集合页 + 编号页；手动停止；当前 shell 显示；编码切换。
- [ ] 新建标签页：打开已有 / 项目中新建会话 / 新建项目。
- [ ] 设置页双栏：通用（常规/外观/i18n/主题/字体/代码高亮）/ 浏览器控制 / 电脑控制 /
  模型（供应商/偏好/MCP与Skill/子代理/长期记忆；插件灰色）/ 权限（网络/终端/文件黑白名单/
  环境变量+CLI key-value）/ 其他（快捷键基础设施/关于）。
- [ ] openWith 右键下拉组合按钮（文件管理器/vscode/vs/sublime/kate/jetbrains/系统默认；
  路径模板设置-环境管理）。※纯 GUI，非工具。
- [ ] 无边框标题栏（Win/Linux X11）+ 横向/垂直 tab + tooltip 全名。
- [ ] i18n 落地（跟随系统，中英先行，编译预处理进 cpp）+ 多套主题深浅色 + 字体/高亮。
- [ ] 空态/错误态/长列表/超大 diff 全覆盖（见 ui-events.md §4）。
